# HACKATHON checklist (kit repo)

This repository is the **hackathon kit** (agents, docs, bridges) — not the SEABW submission app.

## For the real submission app

When official build starts, copy the template to your **app repo root**:

```bash
cp ~/dev/Project/aegis-hackathon-kit/docs/kit/templates/HACKATHON.md ./HACKATHON.md
cp ~/dev/Project/aegis-hackathon-kit/docs/kit/templates/AI_COLLABORATION_LOG.md ./docs/
```

Full lifecycle: [docs/kit/04-hackathon-lifecycle.md](docs/kit/04-hackathon-lifecycle.md)
