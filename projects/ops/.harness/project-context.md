# Agentic Ops — Project Context

## Purpose

Workspace for **non-code goals**: marketing, business strategy, GTM, partnerships, pitch decks, launch plans, and cross-cutting research.

## When to use ops vs product projects

| Goal | Workspace |
|------|-----------|
| Marketing / launch / business plan | **ops** (this project) |
| Product code, contracts, apps | `aegis-rpc`, `kreditagent`, `retropick` |
| Org-wide recall | Hivemind + vault |
| Fleet / harness health | harness root scripts |

## Work patterns

1. **Structured work** — `.harness/tasks/` + Kanban board `agentic-ops`
2. **Free-form notes** — `cli/harness obsidian capture projects/ops "..."` → vault `00-Inbox/` or `01-Projects/Ops/`
3. **Grounding** — `index-project projects/ops` indexes vault folders listed in obsidian.config.json

## Kanban

- Board: `agentic-ops`
- Workspace: absolute path to this directory
