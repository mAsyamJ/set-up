# Hackathon Strategy

Optimize for:
1. Originality
2. Problem-solving
3. Completeness
4. Scalability

Winning demo:
Aegis prevents dangerous Web3 or AI-agent actions before execution.

MVP must include:
- input panel
- risk score
- ALLOW/WARN/BLOCK decision
- explanation reasons
- API response preview
- demo scenarios
- README
- AI collaboration log

Do not build features that cannot be demonstrated.
