# Agent Harness OS — Vision

Reusable **agentic engineering control plane** that attaches to any project via `.harness/` adapter.

- **MCP** — typed tool access from Cursor and Hermes
- **A2A** — agent-to-agent tasks and artifacts on localhost
- **RAG** — retrieval with source hierarchy and citations
- **Obsidian** — human knowledge layer (untrusted context)
- **Hermes** — external 24/7 orchestrator (Telegram, Kanban)

Executable truth lives in the repo; vault notes are reference only.

See [10-portable-workflow-migration.md](kit/10-portable-workflow-migration.md) for the full blueprint.
