# A2A Integration

Server: `runtime/a2a/harness-a2a-server` on `127.0.0.1:8790`

- Agent card: `GET /.well-known/agent.json`
- Tasks: `POST /tasks` with `{ task_id, project, agent, trust, input_artifacts }`

Trust: `local` full access via gateway; `remote` redacted artifacts.

Start: `cli/harness start-a2a`
