# A2A Integration (Disabled)

A2A has no Agent Harness v1 activation gate and is not an operational
interface. The public CLI refuses A2A commands and the server entrypoint fails
closed.

Do not start a listener, add a service, or expose A2A through Hermes or Cursor.
Any future design requires authenticated principals, schema and size limits,
loopback-only binding, approval isolation, adversarial tests, and a separate
reviewed rollout.
