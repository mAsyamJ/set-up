# Aegis Agent Plugins

Runtime-specific prompt plugins for Codex, Kiro, Claude, and Hermes.

Rule:
- Hermes is persistent runtime and gateway.
- Kiro is local model/coding backend via bridge.
- Codex verifies and implements scoped tasks.
- Claude reviews architecture, product, business, and security.

Do not re-enable `telegram-kiro-gateway.service`.
