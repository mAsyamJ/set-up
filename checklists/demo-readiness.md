# Demo Readiness Checklist

## Product

- [ ] Aegis one-liner is clear.
- [ ] Chainlink is described as adapter only.
- [ ] AI explains, policy decides.
- [ ] MVP does not overclaim.

## API

- [ ] `/api/rpc` returns `eth_blockNumber`.
- [ ] `/api/preflight` returns SAFE.
- [ ] `/api/preflight` returns BLOCK for MaxUint256 approval.
- [ ] `/api/events` returns audit events.
- [ ] `/api/adapters/chainlink` returns health.

## Dashboard

- [ ] Event timeline visible.
- [ ] Verdict badges visible.
- [ ] Adapter signals visible.
- [ ] AI memo or fallback visible.
- [ ] Contract addresses visible.

## Contracts

- [ ] Registry deployed or local proof shown.
- [ ] Demo ERC20 deployed or local proof shown.
- [ ] Deployment addresses documented.

## Submission

- [ ] README complete.
- [ ] Vercel deploy works.
- [ ] GitHub repo public or accessible.
- [ ] Demo video recorded.
- [ ] Pitch deck ready.
