# Phase 10 Deploy

## Goal

Deploy frontend to Vercel and contracts to Base Sepolia.

## Scope

Keep this phase narrow. Do not implement stretch features unless all prior phases are passing.

## Required output

- Code or docs committed
- Commands run
- Test evidence
- Demo impact
- Known limitations

## Acceptance checklist

- [ ] Implemented
- [ ] Local test passes
- [ ] Error handling exists
- [ ] README or docs updated if needed
- [ ] Demo flow still works
- [ ] No secrets committed

## Failure fallback

If blocked for more than 45 minutes, simplify to the smallest demo-compatible version and tell Orchestrator.
