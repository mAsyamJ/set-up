# Base Sepolia Deploy Skill

## Purpose

Deploy contracts to Base Sepolia, store addresses, and verify tests.

## MVP implementation

- Keep implementation minimal and demo-focused.
- Provide a deterministic test or curl command.
- Log failures clearly.
- Integrate with audit events when relevant.

## Upgrade path

- Add stronger validation.
- Add richer telemetry.
- Add reusable commands.
- Add failure-mode handling.
- Add production hardening after hackathon.

## Inputs

- Task file from `tasks/`
- Relevant doc from `docs/`
- Product rules from `AGENTS.md`

## Outputs

- Code or documentation
- Acceptance evidence
- Test command
- Known limitations

## Acceptance criteria

- Works locally.
- Supports the demo.
- Does not violate product truths.
- Does not require mainnet funds.
